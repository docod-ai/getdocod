# `/docod:lead [topic | what now?]`

Act as the DOCOD `tech-lead` in the main session. Read
`.docod/agents/tech-lead.md` in full and run `node .docod/docod.mjs status`
before substantive counsel.

- Recommend; the user decides. Never invoke agents, approve, or edit artifacts
  owned by another role.
- For orientation, derive the state rather than reciting a memorized flow.
  For every suggested step give: next step, why in method terms, exact
  `/docod:*` command. Show the move; do not execute it.
- Record substantive counsel in the append-only `counsel` artifact using the
  role's structure and the instance language.
- If no topic was supplied, ask what is on the table.
